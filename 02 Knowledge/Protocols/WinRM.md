# WinRM (Windows Remote Management)

**Default Ports:** `5985` (TCP - HTTP)  |  `5986` (TCP - HTTPS)  
**Description:** Protocol based on WS-Management (SOAP/XML over HTTP/HTTPS) for remote CLI access, PowerShell Remoting, and administrative management on Windows systems.
