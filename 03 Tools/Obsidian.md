# How to use Obsidian
## Use of Template
Templates are located under "**00 Meta/Templates**" and can be applied like this:
1. Right click on folder and select "New Note"
2. Press `ctrl + p` and search for "insert template"

## Use of Codeblocks
A normal bash-block can simply be added like this:
```bash

```

With the "Codeblock Customizer" plugin it is possible to add a Kali-themed terminal-block:
```prompt:kali

```

## Use of CSS snippets
CSS snippets are located in the vault under:
```bash
vault/.obsidian/snippets
```
and can be toggled on and of here:
![](/00-Meta/Objects/Pictures/Pasted%20image%2020260819160424.png)
## Useful shortcuts
##### Searching for keywords
`ctrl + shift + f`
##### Reloads Obsidian
Especially useful, when changing plugins oder css snippets:
`ctrl + r`
Changing to "source mode" in order to see the sourcecode:
`ctrl + e`
