# Proxifier
https://www.proxifier.com/download/#win-tab
Advanced proxy client for Windows that forces system applications (or specific executables) through SOCKS4/SOCKS5 or HTTP proxies. Crucial for routing GUI tool traffic (RDP, Web Browser, Burp Suite, SharpHound) through established pivoting tunnels.
