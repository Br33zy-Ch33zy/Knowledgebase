# Tools

## hash-identifier
```bash
hash-identifier HASH-VALUE
```

## hashid
```bash
hashid "HASH-VALUE"
```
### Parameters
hashid
	`-j` = also outputs the JtR format
	`-m` = also outputs the hashcat mode
## Name that hash
```bash
nth -t "HASH-VALUE"
```
