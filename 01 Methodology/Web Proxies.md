# Web Proxies (Interception Proxies)

**Description:** Essential tools that sit as a Man-in-the-Middle (MitD) proxy between a client (browser, thick client, mobile app) and a target web application. They allow security testers to inspect, intercept, modify, replay, and fuzz HTTP/HTTPS traffic in real-time.
